Start here

You do not need to be a programmer to build something useful. Most tools in the archive started as a conversation with an AI assistant and a real classroom itch. Here is one build, start to finish, in about twenty minutes. Try the finished thing first, then make your own.

The need

You want a countdown on the board for a four-minute turn-and-talk. So you open YouTube, search "5 minute timer", sit through an ad, and get one that plays music you did not ask for. Every single time. It is a small annoyance, it happens weekly, and it is exactly the size of problem worth fixing.

See it before you build it

Two real files, both hosted so you can open them right now. Same teacher, same afternoon, twenty minutes apart.

Build your own in twenty minutes

  1. Open Claude, ChatGPT, or Gemini. Whichever one you already have. Paste this in.

    The starter prompt 
    I'm a teacher and I have never written code before. I want a countdown timer I can show on my classroom projector.

I should be able to type in a number of minutes, press start, and watch it count down in big numbers.

Please make it one single HTML file with everything inside it, so I can save it and open it by double-clicking. Do not use any libraries or anything I have to install.

After the code, tell me in plain language how to save the file and open it.

  2. It will hand you a block of code. Copy the whole thing.

  3. Open a plain text editor and paste it in. Save it as timer.html.

    On a Mac, TextEdit starts in rich text and will quietly break the file. Open TextEdit, then Format → Make Plain Text, then paste and save. On Windows, Notepad works as is. Make sure the name ends in .html and not .txt.

  4. Double-click the file. It opens in your browser and it works.

    There is no website to set up and nothing to sign up for. A single HTML file runs straight off your own computer.

  5. Use it in class tomorrow. That is the whole build.

Then keep going: three rounds

Nothing below came from planning ahead. Each one came from putting the timer on an actual projector and finding out what was wrong with it. Paste these into the same conversation, one at a time.

Round 1: nobody could read it

The numbers were fine on a laptop and useless from the back row, and when it hit zero the screen just sat there.

What I asked next 
Two problems when I used this in class today.

The numbers are too small to read from the back of the room. Make them fill most of the screen.

And when it reaches zero, nothing happens, so I miss it while I'm talking to a student. Make the whole screen change colour and say the time is up.

Round 2: it ran at double speed

I tapped Start twice because I was not sure the first tap landed. The clock started eating two seconds a second.

What I asked next 
There's a bug. If I press Start twice, the timer counts down twice as fast, and pressing it three times makes it three times as fast.

Please fix it so pressing Start again does not stack up extra timers, and explain in plain language what was causing it.

Ask for the explanation, not just the fix. This one is worth understanding: every press was starting a brand new clock and none of them were ever stopped. It is one of the most common bugs in AI-written timers, and once you have seen it you will spot it everywhere.

Round 3: it did not fit how I actually teach

A discussion was going well and I had no way to hold the clock. And I was typing "4" into the box for the fourth time that day.

What I asked next 
Two more things.

I need to pause the timer when a discussion is running long, and then resume it, plus a reset button that puts it back to the start.

And I use the same few lengths every day, so add quick buttons for 1, 2, 3, 5 and 10 minutes instead of typing the number each time.

Three rounds, maybe fifteen more minutes, and the second demo above is what came out. That sequence is the prompt journey, and it is the thing this community actually shares. Not the finished file. The wrong turns.

Putting it online, if you want to

You do not need to. The file works on your own machine and that is enough for most tools. You only need a web address when a colleague asks for it, or when you want to submit a build so others can try it.

When that happens: go to Netlify Drop, drag your timer.html onto the page, and it hands you a link that anyone can open. No account needed to try it. That is the entire step.

GitHub Pages, Vercel and Google Apps Script all do the same job and are worth knowing later. Pick one thing now, not four.

What round four would be

The classroom version above is not finished, and it is on the site anyway. The space bar should start and pause it. There should be a fullscreen button. A soft chime at zero would help on days the projector is behind you. None of that is built yet.

That is deliberate. Small and real beats ambitious and abandoned, and a tool you actually used this week is worth more than one you are still perfecting. Half-working counts. Bring it anyway.
